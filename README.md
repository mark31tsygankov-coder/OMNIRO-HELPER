# OMNIRO HELPER

Игровой справочник RADMIR CRMP для Windows (Python + PySide6 + SQLite).

## Собрать EXE с телефона (без Python)

1. Создайте репозиторий на github.com (кнопка **New**, имя любое, можно Private).
2. Распакуйте ZIP и загрузите **содержимое папки** через **Add file → Upload files**.
   ⚠️ Папка `.github` скрытая: если телефон её не показывает, создайте файл
   `.github/workflows/build.yml` вручную (Add file → Create new file) и вставьте текст из этого проекта.
3. **Settings → Secrets and variables → Actions → New repository secret**:
   имя `ADMIN_PASSWORD`, значение — ваш пароль администратора (минимум 10 символов). Запомните его!
4. Вкладка **Actions → Build Windows EXE → Run workflow**.
5. Через 3–5 минут откройте завершённый запуск → внизу **Artifacts → OMNIRO_HELPER_EXE** → скачайте.

> Пароль меняет ключ проверки: если смените `ADMIN_PASSWORD`, все ранее выданные ключи перестанут работать.

## Админ-панель
- На экране активации: 7 быстрых нажатий по названию **OMNIRO HELPER** за 5 секунд.
- В программе: 7 быстрых нажатий по ⚡ за 5 секунд.
- Логин `omniro_boss`, пароль — тот, что в `ADMIN_PASSWORD`.
- Пароль нигде не хранится: из него при входе вычисляется ключ подписи; в программе лежит только публичный ключ.

## Обновление данных без пересборки
Положите JSON в `%APPDATA%\OmniroHelper\user_data` (или кнопка «Импорт JSON» в настройках). Формат — в «База знаний».

## Ограничения
Офлайн-защита не абсолютна: опытный человек может изменить программу. Отзыв ключа работает после распространения `revoked.json`.
